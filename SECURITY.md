# Security

The gateway is intended for a single trusted user on a local machine. It is not a multi-tenant
hosted service. Keep provider and gateway tokens private. Do not expose the gateway directly to
the Internet or place bearer tokens in browser applications.

Use GitHub's private vulnerability reporting for security issues when enabled on this repository.
Do not open a public issue containing credentials, private logs, or a working exploit against
someone else's account. Revoke any credentials you accidentally expose.

Only the current source version is maintained. Security reports are handled on a best-effort basis;
there is no promised response time or commercial security support.
